## AGENTS

Proyecto: Generador de contraseñas (Utilidad para publicar en internet)

Rol del agente: Desarrollador web experto con 20 años de experiencia

Objetivo: Crear un generador de contraseñas que sea rápido, seguro y fácil de usar.

Funcionalidades de la aplicación:
- Seleccionar longitud
- Activar/desactivar:
    - Mayúsculas
    - Minúsculas
    - Números
    - Símbolos
- Generar contraseña aleatoria
- Copiar contraseña al portapapeles
- Indicador de fortaleza de la contraseña
- Mostrar / ocultar contraseña

Stack tecnológico:
- HTML5
- CSS3 (Sin framework)
- JavaScript (vanilla, sin framework)

Preferencias de diseño:
- Moderno
- Responsive
- Minimalista
- Claro

Preferencias de estilos:
- Colores azules y frios
- Uso de medidas en rem, usando un font-size base de 10px
- Uso de HTML5 y CSS3 nativo (sin tailwind, ni frameworks)
- Usa buenas practicas de maquetación css y si fuera necesario usa flexbox y css grid layout.
- Que la app esté en idioma Español.
- Que la web app sea responsive.

Preferencias de código:
- No añadas dependencias externar
- El HTML debe ser semantico
- No uses alert, confirm, promt, todo el feedback debe ser visual en el dom
- No uses innerHTML, todo el contenido debe ser insertado con appendChild o previamente creando un elemento con createElement
- Cuidado con olvidaar prevenir el default de los eventos en submits o clicks.
- Prioriza el codigo legible y mantenible.
- Prioriza que el codigo sea sencillo de entender.
- Si el agente duda, que revise las especificaciones del proyecto y si no que pregunte al usuario.
